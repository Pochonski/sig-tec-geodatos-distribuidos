# Datos de referencia

`cartago/*.geojson` y `sedes.json` contienen datos derivados de OpenStreetMap.
Se distribuyen bajo [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

**© OpenStreetMap contributors** · [Atribución y licencia](https://www.openstreetmap.org/copyright).

La licencia indicada corresponde a estos datos. La elección de licencia para
el código del proyecto continúa a cargo del equipo.

`cartago/fuentes.json` registra origen, fecha de extracción, conteos y hashes.
`sedes.json` usa los objetos OSM enlazados en
[la documentación de mapas](../../../docs/mapas-campus.md). Sus cajas son
encuadres de navegación, no una delimitación oficial de las propiedades.

Los datos son comunitarios y no están validados en campo. No incluyen un
inventario completo de iluminación o accesibilidad. Los detalles de cobertura,
transformación, actualización y uso están en la documentación de mapas.
